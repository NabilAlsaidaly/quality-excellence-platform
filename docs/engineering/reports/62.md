## Implemented application behavior

The trusted internal fixture bootstrap persists a finite structural Document capability through unchanged RoleManagement, plus explicit operation assignments. The issuer has no content access. Editor has institution create/list; reader has list only. Each new document receives exactly six resource assignments: editor view/metadata/append/history and reader view/history. Creator status, membership, role name or owning unit alone grants nothing. No delegation or universal administrator exists. All assignments are immediately effective for exactly24 hours; the named institutional issuer can revoke them. A revoked/expired assignment is checked again on every operation, including old sessions.

`DocumentWorkspaceAccess` is bound through a WeakMap to the exact server-created Request, connection/PDO and verified disposable database UUID. APP_ENV=testing or a submitted header/config value alone cannot enable it. Actual institutional provider, active guard, current password hash, tenant and membership are required. The real auto-discovered DocumentPolicy evaluates finite operations inside the existing transaction boundary. Ordinary requests have no trusted fixture proof and deny access. The temporary capability registry addition is restored in finally; no registry/config source is modified.

Listing joins current resource assignments before SQL search/count/sort/pagination, never filters an unrestricted result in PHP. Current metadata uses a joined latest-revision anti-join, avoiding a stale scalar subquery under REPEATABLE READ. Projections contain public ULIDs and permitted metadata/authorship/time only, never storage keys, bytes, filenames, hashes or internal IDs.

Creation reuses the existing standalone file-write/completeWrite boundary. The optional afterPersist callback inserts all initial grants and audits in the same SQL transaction as Document+Version. Append's optional side-effect-free callback checks actual authorization before and after version SQL. Original callers omit the optional argument and keep their behavior/return shape. Files are prepared outside SQL transactions; failure compensates only the attempt's exclusively owned bytes. Existing ambiguous-commit conservative retention is unchanged. No stream/path/UploadedFile is accepted from this UI: only harmless server-generated synthetic content.

Metadata writes preserve original Document columns and add immutable complete snapshots with actor/time and incrementing version. Expected public revision token rejects stale edits with409; no-op creates no history. Original UTF8 validation and65535-character capacity are reused. Model update/delete is refused for new history; privileged raw SQL is not made WORM/immutable by this design.

Grant/revocation/observed-expiration/access-denied events are persisted with scoped attribution. Expiration observation is once per assignment under a current row lock and unique event key. Visibility checks do not fabricate denial events; unverifiable sessions/memberships/passwords or missing/foreign resources do not create a misleading actor/resource audit.
