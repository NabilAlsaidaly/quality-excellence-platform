# دليل العرض المحلي للمالك — المراجعة والنضج

الهدف: عرض خاص يوم12 نوفمبر2026، بتصنيف **TEST_ONLY** وبيانات خيالية وسياسات Laravel الفعلية ومكونات Filament5 الأصلية. [اعتماد Issue62 المحدد](https://github.com/NabilAlsaidaly/quality-excellence-platform/issues/62#issuecomment-6769110851) لا يحسم المنح التشغيلية أو T17 أو إعادة التقييم. لا دمج أو نشر.

## ما يعمل فعليًا

| الشاشة | السلوك المثبت والحدود |
|---|---|
| الدخول والحساب والخروج | الواجهات والجلسات الأصلية دون تعديل المصادقة أو رابط المساحة المعتاد |
| بنك المراجعة والنضج | المنهجية المسندة صراحة في لوحة أصلية معزولة؛ لا وصول من الاسم أو العضوية |
| المحتوى والمراجعة | حفظ يفتح مراجعة تلقائيًا، تصحيح، إصدار مصحح واعتماد مستقل وتاريخ محفوظ |
| المراحل الخمس | أسئلة وشواهد متوقعة وسلم اختباري قابل للضبط، إجابات محفوظة وتقييم يدوي مرتب |
| الشواهد | إصدارات اصطناعية محددة ومخوّلة عبر DocumentPolicy؛ لا إتاحة ملفات |
| الإشعارات | حفظ ذري من حدث المراجعة، قراءة/عدم قراءة وروابط تعيد التحقق من الصلاحية |
| بنك الوثائق داخل اللوحة | DocumentResource الأصلي وسياسة الوثائق نفسها؛ لا رفع أو تنزيل |

الرحلة الكاملة اجتازت87 تحققًا بالمتصفح و19 تحققًا مستقلًا من MySQL، مع15 لقطة عند أحجام عرض1280/768/375. راجع [التقرير62](../reports/62.md) و[أداة العرض](../../../tests/Browser/ReviewMaturity/README.md). تبقى الأدلة والحسابات خاصة داخل المشروع.

## تجهيز عرض جديد

تحقق من التزام Draft PR ونجاح CI. حافظ على عمل الزميل والديمو السابق. استخدم PHP8.4 وDocker وصورة MySQL8.4.13 وPlaywright المثبتة أصلًا، واعتمادات المشروع وأصول Vite المبنية. لا تثبت حزمة ولا تغير `.env` أو إعدادات PHP/MySQL العامة. لا توجه الأداة إلى `quality_platform`، ولا تشارك قاعدة العرض الحية مع PHPUnit.

اختر اسم تشغيل جديدًا. الأداة ترفض اعتماد مجلد أو قاعدة موجودة. جهز السيناريو في يوم العرض؛ الإسنادات فعالة24 ساعة فقط، ولا تمددها الجلسة المفتوحة.

```powershell
$php = 'C:\path\to\existing\php.exe'
$cli = 'C:\path\to\existing\playwright-cli.cmd'
& tests/Browser/ReviewMaturity/Run.ps1 -Mode Prepare -RunName browser-90 -Php $php
& tests/Browser/ReviewMaturity/Run.ps1 -Mode Demo -RunName browser-90 -Php $php -PlaywrightCli $cli
```

تطبع الأداة عنوان الدخول المحلي الفعلي على127.0.0.6، وتترك خادمها عاملًا حتى انتهاء التجربة. افتح الملف التالي محليًا في محرر نصوص لاسترجاع المؤسسة والبريد وكلمة المرور العشوائية:

`.local-tools/reports/issue62/review-maturity/browser-90/fixture.json`

لا تطبعه في الطرفية ولا تنسخه إلى Git أو PR أو السجلات. استخدم `author` للمؤلف و`reviewer` للمراجع في ملفي متصفح مستقلين. حسابات `issuer` و`quality` و`foreign` حالات تحقق من رفض لوحة المراجعة، وليست منحًا للمحتوى.

## الرحلة اليدوية

1. سجّل دخول المؤلف بالنموذج الأصلي وافحص الحساب. على أصل العنوان المحلي نفسه افتح `/institution/mvp-workspace/workflows`. لم يتغير رابط الحساب المعتاد؛ المراجع المستقل لا يحصل على دخول J03 تلقائيًا.
2. افتح المنهجية الخيالية المنشأة بأكشن J03 الفعلي. اختر «تحرير المحتوى» واحفظ نصًا. يُحفظ الإصدار والمراجعة والإشعار معًا دون زر إرسال مستقل.
3. بجلسة المراجع افتح المنهجية، واختر «قرار المراجعة» ثم «طلب تصحيح» مع ملاحظة. لا يتوفر له تحرير المحتوى.
4. أعد تحميل صفحة المؤلف وافحص الملاحظة واحفظ التصحيح. بالمراجع اعتمد الإصدار الجديد، وافحص بقاء قرار التصحيح السابق. لا يتوفر للمؤلف اعتماد نفسه.
5. بالمراجع افتح «التوجه» ثم «إعدادات المرحلة». أضف سؤالًا وتعليمات وشاهدين متوقعين، وحدد الإلزام صراحة. أضف حالات السلم وحدودها وأوصافها. هذه قيم عرض يختارها المستخدم وليست استبيانًا أو سلمًا تشغيليًا معتمدًا.
6. بالمؤلف حرر الإجابة واربط كل شاهد متوقع بالإصدار الاصطناعي المخوّل من القائمة واحفظ المسودة. يجوز حفظ مسودة ناقصة؛ الاعتماد يرفضها حتى استيفاء المطلوب.
7. بالمراجع افحص الإجابة والإصدار المرتبط واختر تصنيفًا يدويًا مع تعليل. قبول الشاهد يخص هذه الإجابة الاختبارية؛ لا يعتمد الوثيقة مؤسسيًا ولا يثبت فحص ملف حقيقي.
8. اعتمد أدنى تصنيف وافحص فتح «النظام» ثم «التنفيذ» ثم «القياس» ثم «التحسين والتطوير» بالترتيب. لا درجة دقيقة أو متوسط أو نسبة إجمالية مختلقة.
9. افحص لقطة الأسئلة والإجابات والسلم والشواهد المحفوظة عند الاعتماد. تغيير إعدادات مستخدمة ينشئ إصدارًا جديدًا ويبقي اللقطة السابقة. استبدال تقييم سابق وإعادة التقييم غير متاحين حتى حسم D014.
10. افتح «الإشعارات»، وغيّر القراءة وافتح الرابط المحمي. افحص بنك الوثائق دون رفع أو تنزيل.
11. جرّب المؤسسة الأخرى والحسابات غير المخولة؛ تُرفض المساحة. ارجع للحساب وسجّل الخروج ثم تحقق من رفض الوصول المحمي بالجلسة المنتهية.

تشمل الاختبارات الآلية أيضًا سحب الإسناد والدور والصلاحية والعضوية وتغيير كلمة المرور وانتهاء المدة والقرار القديم والتراجع عند فشل الإشعار. لا تقبل هذه النتائج إصلاح T17 العام.
