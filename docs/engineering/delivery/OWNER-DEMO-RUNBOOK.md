# دليل العرض المحلي للمالك — 12 نوفمبر 2026

الهدف عرض وظائف حقيقية ببيانات خيالية داخل بيئة اختبار محلية. هذا الدليل لا يفعّل صلاحيات تشغيلية ولا يصف إطلاقًا إنتاجيًا. يُحدَّث إثبات كل رحلة بعد تنفيذها فعلًا؛ شاشة العرض القديمة `/admin/ui-preview` ليست مسار القبول.

| المنهجيات | إنشاء وإسناد صريح وبيانات ومسودات وتاريخ | سيناريو J03 الاختباري المقبول؛ ليس منحًا تشغيليًا عامًا |
| الوثائق | إنشاء محتوى اصطناعي، بيانات وصفية، إصدار جديد، تاريخ وقارئ مستقل | PR64 المقبول؛67 تحققًا بالمتصفح وقراءة MySQL؛ لا رفع أو تنزيل |

| الإشعارات والشواهد | الربط المستمر وسجل القراءة ضمن طلب التعديل | لا توجد حتى الآن رحلة مراجعة متصلة تُثبت إرسالها |

دليل التقرير الحالي: [Issue62](../reports/62.md). لا تكفي اختبارات القيم المستقلة لإعلان رحلة مراجعة أو تقييم محفوظة في MySQL.

## قبل العرض

1. تحقق من الفرع والالتزام ونجاح CI الفعلي المسجل في PR، ومن نظافة شجرات العمل. اترك عمل الزميل والديمو السابق كما هما.
2. استخدم PHP وDocker وMySQL8.4 وPlaywright المثبتة أصلًا، واعتمادات المشروع وأصول Vite المبنية. لا تثبت حزمًا أو تغير إعداد PHP العام أو `.env` المعتاد.
3. استخدم قاعدة اختبار جديدة ومملوكة للأداة باسم `quality_platform_ci` مع تحقق UUID. لا توجه الأداة إلى `quality_platform` أو قاعدة ديمو مأهولة.
4. اختر اسم تشغيل جديدًا؛ الأدوات ترفض اعتماد مجلد/قاعدة موجودة. تبقى كلمات المرور والمؤسسات الخيالية في ملفات خاصة مستبعدة من Git.

## عرض الوثائق المتاح الآن

هذه الأوامر تستخدم الأداة المدققة الموجودة، وتترك فقط خدمتها الجديدة عاملة للاستخدام اليدوي. المسارات أدناه أمثلة لمواضع البرامج المثبتة؛ استبدلها بمواقعها المحلية دون تنزيل حزمة جديدة.

```powershell
$php = 'C:\path\to\existing\php.exe'
$cli = 'C:\path\to\existing\playwright-cli.cmd'
& tests/Browser/DocumentWorkspace/Run.ps1 -Mode Prepare -RunName browser-90 -Php $php
& tests/Browser/DocumentWorkspace/Run.ps1 -Mode Browser -RunName browser-90 -InspectOnly -Php $php -PlaywrightCli $cli
```

تطبع الأداة عنوان الدخول المحلي الفعلي. افتح ملف الحسابات الخاص محليًا في محرر نصوص:

`.local-tools/reports/issue62/documents/browser-90/fixture.json`

استخدم بيانات المؤسسة والبريد وكلمة المرور من حساب `editor` ثم `reader`. لا تنسخ محتوى الملف إلى Git أو سجلات التحقق أو PR. لا تستخدم حسابًا حقيقيًا.

1. سجّل دخول المحرر عبر نموذج الدخول المؤسسي الحالي، ثم تحقق من صفحة الحساب.
2. افتح أصل العنوان المحلي الذي طبعته الأداة مع المسار `/institution/document-workspace/documents`.
3. أنشئ وثيقة اختبارية بعنوان ووصف واضحين. محتواها بايتات اصطناعية آمنة ينشئها الخادم؛ لا يستقبل ملفًا منك.
4. افتح الوثيقة وعدّل بياناتها، ثم أنشئ إصدارًا اختباريًا جديدًا وأعد تحميل الصفحة.
5. افحص إصدارات المحتوى وسجل البيانات الوصفية والبيانات الأصلية المحفوظة.
6. افتح جلسة متصفح منفصلة للقارئ، وتحقق من القراءة والتاريخ وغياب أفعال التعديل، ثم سجّل الخروج.

هذا عرض مستقل للوثائق. صفحة الحساب لا تدّعي وجود رابط تشغيلي موحد للوثائق والمراجعات. تُعرض رحلة المنهجيات من الديمو السابق المحفوظ بعنوانه المحلي الموجود في التسليم الخاص؛ لا تُعد تشغيله أو تصفر بياناته لاتباع هذا الدليل.

## الرحلة المتصلة المستهدفة بعد الاعتماد

لا تبدأ هذه الخطوات قبل اكتمال تعديل المراجعة والنضج واعتماده واختباره. تُنفذ عبر لوحة اختبارية أصلية مستقلة، مع المصادقة والسياسات الفعلية، وتظل منفصلة بوضوح عن تنقل العميل التشغيلي.

1. الكاتب يحفظ محتوى فعليًا؛ يُنشأ سجل مراجعة وإشعار مصرح به من معاملة الحفظ نفسها دون زر إرسال مستقل.
2. المراجع المستقل يقرأ الإصدار المحدد ويطلب تصحيحًا بملاحظة.
3. الكاتب يرى الملاحظة ويحفظ التصحيح؛ تبقى المراجعة السابقة ويُفتح إصدار جديد.
4. المراجع يعتمد الإصدار الحالي؛ يُرفض الاعتماد الذاتي والقرار القديم بعد تعديل أحدث.
5. تُضبط الأسئلة والشواهد المتوقعة وسلم الحالات من الواجهة، ثم تُحفظ الإجابات وروابط إصدارات الوثائق الاصطناعية المسموحة.
6. المراجع يختار حالة تقييم بشرية ويسجل سبب الحكم؛ اعتماد أدنى حالة يفتح المرحلة التالية.
7. تتكرر الخطوات للمراحل الخمس بالترتيب، مع فحص قفل المسارات المباشرة دون سند اعتماد سابق.
8. يُقرأ التاريخ القديم للأسئلة والإجابات والسلم والشواهد والقرار بعد تغييرات الإعدادات، وتُفحص حالة قراءة الإشعارات.
9. تُعاد المحاولة بمستخدم غير مخول ومؤسسة أخرى وبعد سحب الإسناد وانتهائه، دون تسريب محتوى.

لا نسبة كلية أو متوسط مختلق. إعادة التقييم وآثارها على المراحل التالية تبقى محجوبة حتى حسم D014، وموضع السلم التشغيلي D003 غير محسوم. لا اعتماد مؤسسي تلقائي للوثيقة من قبول شاهد، ولا ترخيص مرجعي مفترض أو رفع/تنزيل غير معتمد.

## إثبات العرض

لكل رحلة مكتملة: سجّل الالتزام الفعلي، وأسماء الشاشات، والقراءة المستقلة من MySQL بعد إعادة التحميل، ونتائج المستخدمين المختلفين، ولقطات375/768/1280. تحفظ اللقطات والسجلات والحسابات في مجلد الأدلة الخاص داخل المشروع؛ ينشر التقرير المنقح فقط. وضّح «عُرض بالمتصفح / حُفظ في MySQL / ما زال محجوبًا» دون تحويل اختبارات المجال إلى قبول تشغيلي.

## التنظيف بعد انتهاء العرض اليدوي فقط

```powershell
& tests/Browser/DocumentWorkspace/Run.ps1 -Mode Cleanup -RunName browser-90 -Php $php
```

تتحقق الأداة من ملصقات الحاوية والجلسة والحجم الحصري وPID ومسار الخادم قبل إزالة مواردها فقط. لا تستخدم تنظيف Docker أو Redis أو العمليات بصورة عامة. لا توقف الديمو السابق. احفظ إيصال التنظيف والتقرير الخاص للمراجعة؛ لا تدمج أو تنشر المشروع من هذا الدليل.
