# المنتج والقدرات

إصدار 1.0، تحقق 12 نوفمبر 2026، Issue [#71](https://github.com/NabilAlsaidaly/quality-excellence-platform/issues/71). المصدر المقروء `main@03c829fde71bbb11754ef657bf2edfe50253068e`؛ [CI بعد الدمج](https://github.com/NabilAlsaidaly/quality-excellence-platform/actions/runs/43289862828) ناجح.

تعني `IMPLEMENTED_TEST_ONLY` وجود تنفيذ مثبت داخل سيناريو معزول مؤقت، و`PARTIAL` وجود جزء عامل، و`GATED_OWNER_DECISION` اعتمادًا تشغيليًا غير محسوم، و`NOT_IMPLEMENTED` غياب الرحلة. لا تُستخدم `OPERATIONAL_ACCEPTED` دون قبول مالك مستقل L4. نجاح الاختبارات لا يمنح مستخدمًا صلاحيات ولا يقبل المتطلبات الـ105 مجتمعة.

المنصة تربط منهجية المؤسسة بوحدتها المسؤولة، ومحتواها ووثائقها وشواهدها ومراجعاتها ومراحل نضجها. المثال المثبت يبدأ بمؤلف يحفظ مسودة، ومراجع مستقل يطلب تصحيحًا ثم يعتمد لقطة محددة، ويستمر عبر خمس مراحل ثم إعادة تقييم تاريخية. لا توجد درجة كلية آلية أو نسب إنجاز معتمدة. المرجع [الرحلات](../engineering/delivery/JOURNEYS.md) و[قرارات التنفيذ](../engineering/delivery/DECISIONS.md).

| القدرة | التنفيذ الفعلي | الحالة وحد التشغيل |
|---|---|---|
| الدخول والاستعادة والحساب | InstitutionEntry/InstitutionRecovery وصفحات عربية أصلية | PARTIAL؛ local/testing فقط، لا إنشاء موظفين تشغيليًا |
| المؤسسة والوحدات | إنشاء واسم ونقل وشجرة ومنع الدوران وتاريخ تغييرات | IMPLEMENTED_TEST_ONLY داخل العرض؛ D002 محجوب |
| بنك المنهجيات | إنشاء ذري مع إسناد صريح، بيانات ومسودة وتاريخ وقائمة مرشحة بالإسناد | IMPLEMENTED_TEST_ONLY؛ لا امتياز تلقائي للمنشئ |
| الوثائق | PDF/DOCX حقيقيان، نسخ ثابتة، بيانات وصفية، إتاحة مستقلة وتنزيل خاص لنسخة دقيقة | IMPLEMENTED_TEST_ONLY لعينات معروفة غير مفحوصة؛ لا فحص إنتاجي |
| المراجعة | إرسال وتصحيح وقرار مستقل وسجل ثابت | IMPLEMENTED_TEST_ONLY؛ لا نشر عام أو اعتماد وثيقة مؤسسي |
| النضج | التوجه والنظام والتنفيذ والقياس والتحسين والتطوير، أسئلة/سلم/شواهد محفوظة | IMPLEMENTED_TEST_ONLY؛ التصنيف يدوي ضمن snapshot معتمد للعرض |
| إعادة التقييم | أقل/مساو/أعلى، تصحيح، اعتماد مستقل، إعادة تحقق لاحقة متسلسلة | IMPLEMENTED_TEST_ONLY؛ D014 التشغيلي غير مقبول |
| الإشعارات | داخل التطبيق، حفظ ذري وقراءة/غير مقروء | IMPLEMENTED_TEST_ONLY؛ لا SMS أو إرسال تشغيلي خارجي |
| المراجع والعلاقات المرخصة | مبادئ/مصادر قيد القرار | NOT_IMPLEMENTED؛ المصدر والترخيص والدلالات غير محسومة |
| الاستضافة والإطلاق | لا نشر من هذه المهمة | NOT_IMPLEMENTED؛ لا قبول إنتاجي |

المستخدمون الممثلون في العروض أدوار fixture، لا قائمة أدوار مؤسسية معتمدة. جودة التجربة تعتمد على فصل المؤلف والمراجع والمُصدر والقارئ، وعلى مؤسستين لإثبات الرفض المتبادل. [خريطة الهوية](04-IDENTITY-ACCOUNTS-AND-PERMISSIONS-AR.md) تفصل البيانات عن التفويض.
